# Secure Remote Command Executor

## Description
A client-server application demonstrating secure remote command execution with SSL/TLS encryption and authentication.

## Features
- SSL/TLS encrypted communication
- Password-based authentication
- Command whitelisting for security
- Web-based interface
- Cross-platform compatibility

## Setup
1. Run `chmod +x setup.sh && ./setup.sh`
2. Start server: `./server 8443`
3. Open `index.html` in your browser
4. Connect using password: "secret"

## Security Note
This is an educational demonstration. In production, implement proper security measures.
